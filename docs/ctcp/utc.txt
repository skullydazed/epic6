# CTCP UTC

## Synopsis

```irc
/ctcp <target> utc <time-value>
```

## Description

Send a timestamp for the receiving client to render in its own local date/time representation. `<time-value>` is an integer number of seconds since the Unix epoch, as returned by `$time()`. Unlike [`ping`](ping.md), it does not use a separate microsecond field. See [`ctcp`](../commands/ctcp.md).

This is intended as a local text transformation, not a request for an automatic network reply. EPIC6 supplies the conversion in [script/ctcp](../../script/ctcp), loaded by [script/builtins](../../script/builtins). Both its request and response handlers return `$stime($3-)`. The result uses the receiving host's local timezone and locale-dependent `%c` date/time format.

The script registers a whole-message replacement. In the current parser, a nonempty handler result replaces text before and including the CTCP, while text after it is appended again. Consequently, a prefix such as `Away since ` can be lost; use the CTCP as the whole message when that distinction matters. The handler is not marked special, so generic CTCP hooks and diagnostics can also occur.

A missing timestamp or the value `-1` produces no replacement. Values that the platform cannot represent or convert produce `value <invalid>`. Supported ranges depend on the platform; supply a valid integer timestamp.

The original document warned that malformed timestamps had crashed older clients. Support and input handling vary across implementations; do not assume another client implements EPIC6's conversion behavior.

## Example

At the interactive prompt, explicitly expand the current timestamp:

```irc
/eval ctcp john utc $time()
```

The original example used an away alias to remember a departure timestamp and included `UTC` in an automatic notice reading “Away since …”. That illustrates the intended local-time rendering, but embedding a leading label is subject to the replacement behavior described above. The displayed date also depends on the sender's clock value and the receiver's timezone configuration.
