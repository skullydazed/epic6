# EPIC release notes archive

Release and development notes are shipped with the source. See [UPDATES](../../UPDATES) for development changes and [KNOWNBUGS](../../KNOWNBUGS) for retirement and outstanding-work records. The current tree identifies itself as EPIC6; this page preserves the original EPIC5 release index through August 2024, not a current-release recommendation.

The **Archived ID/date** columns retain the original index values. **Repository check** reports tagged `source/irc.c` metadata where it differs, including the source version string, internal commit ID, and `internal_version` date. A source constant or Git commit date is not necessarily a public announcement date; some historical source constants are themselves inconsistent. Conflicts are shown explicitly rather than silently choosing one date.

The old release-page identifiers are retained as code references when no local Markdown page exists. They do not imply that a missing page has been created.

## Reading the discrepancies

- The 2.1.9 tag has source commit ID 2053, whereas the archive lists 2052. The 1.1.8 source ID is 1775, whereas the archive lists 1776. Other ID differences are recorded in the table.
- The 2.0 tagged source date is February 12, 2016; the archive lists January 30. The 1.1.6 tagged source date is July 31, 2013, while the archive lists 2012.
- The 1.1.11 source date says 2014, but its Git release commit and archived date are in 2015. Do not treat every `internal_version` value as independently verified publication history.
- The 2.1.3/2.1.4 tags and dates reflect a release-date correction in repository history. The 2.1.3 tag commit is dated March 26, 2021; 2.1.4 follows with the message “I goofed the date - new release.” Its source constant still differs from some other date records.
- The archive marks 2.1.8 skipped even though a tag with that name exists. That tag points to source still identifying itself as 2.1.7, so its existence alone does not establish a coherent 2.1.8 release record.
