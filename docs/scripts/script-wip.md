# Script documentation: work in progress

## Synopsis

```text
/load <script>
```

`<script>` is a placeholder for the script being documented. See [load](../commands/load.md); the command is registered and implemented in [source/commands.c](../../source/commands.c).

## Work in progress

The script is a work in progress, or its author has not supplied enough documentation or detail to document it properly. Read the script's source to determine whether it provides something you can use. Bundled scripts are in the [script directory](../../script/).

This notice expresses the original hope that the author will provide documentation in the future; it does not establish the current status of a particular script.
