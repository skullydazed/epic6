# functions script

## Synopsis

```irc
/load functions
```

## Description

This supplied script defines functions for text display and list manipulation. It selects the PF loader when necessary. After loading, call a helper as `$name(arguments)` in a script expression or expansion.

The original page highlighted these compatibility helpers:

| Function | Behavior |
| --- | --- |
| `format(<width> <text>)` | Right-align text when its tested length is below the width; otherwise return it unchanged. |
| `lformat(<width> <text>)` | Left-align text under the same condition. |
| `pluck(<variable-name> <word>)` | Remove the first matching word from the named variable, update that variable, and return its new value. |
| `notword(<index> <list>)` | Call the built-in [`notw`](../functions/notw.md) to remove a word by index. |
| `remove(<word> <list>)` | Call the built-in [`remw`](../functions/remw.md) to remove the first matching word. |

`format()` and `lformat()` differ from unconditional `$[width]variable` formatting by checking length before applying a potentially truncating field format. Their guard counts bytes, while field formatting operates on display width, so the simple promise about alignment is not reliable for every Unicode or control-code string. They also overwrite the global scratch variable `IRCII.word`. The script itself identifies the current [`pad`](../functions/pad.md) built-in as their replacement for new code.

`pluck()` is not merely a synonym for `remw()`: it takes a variable name and mutates that variable. The original page's description of all three compatibility names as plain aliases omitted this distinction.

The current file also defines numeric minimum/maximum helpers, regular-expression filters, range and mask helpers, shuffling, word/field selection, character splicing, and channel-status selectors. Many historical helpers were superseded by built-ins, but it is inaccurate to describe the present collection as mostly commented-out definitions. Its retained `mychats()` alias calls the removed `dccctl()` interface and cannot enumerate built-in DCC Chat sessions in EPIC6.

See the [function overview](../special/functions_overview.md) for the client's built-in function reference, replacing the original page's old “Section 6” help-file reference. Each underlying function retains its own argument and quoting rules.

## Example

In a script, after loading the helper collection:

```irc
@ example_words = [one two three];
echo $pluck(example_words two);
```

This prints `one three` and also changes `example_words` to that value. At the interactive prompt, use `/eval echo $lformat(8 hello)` to request script expansion explicitly.
