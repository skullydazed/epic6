# DCC RAW (removed)

## Former synopsis

```irc
/dcc raw <fd> <host> <message>
```

## Current status

EPIC6 has removed the built-in DCC command and raw DCC transport. Neither `/dcc raw` nor `/msg =<fd>` sends through a built-in DCC socket. The current `connect()` and `listen()` function entries return an empty string through their active implementation branches; they do not create the connections described here. The former `DCC_RAW` and `DCC_CONNECT` hooks are absent.

## Historical behavior

DCC Raw supplied the underlying transport for `/msg =<fd> <message>`. The latter was preferred because it did not require the script to retain the connection's hostname.

| Value | Historical source |
| --- | --- |
| `<fd>` | Result of `connect()`, `$1` in `ON DCC_RAW "% % N %"`, or `$2` in `ON DCC_CONNECT "% RAW % %"`. |
| `<host>` | First argument originally passed to `connect()`, `$0` in that `DCC_RAW` hook, or `$0` in that `DCC_CONNECT` hook. |

These were identifiers for the removed raw-connection subsystem, not arbitrary file descriptors usable with current message commands.

## Historical examples

These identify obsolete raw-socket usage and are not supported EPIC6 DCC sends:

```irc
/dcc raw 6 blah.foo.com This is a sample message.
/msg =6 This is a sample message.
```
