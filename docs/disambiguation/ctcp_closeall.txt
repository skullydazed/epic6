# DCC CLOSEALL (removed)

## Former synopsis

```irc
/dcc closeall
```

## Description

Historically, this command closed every open or pending DCC connection and sent the applicable CTCP DCC Reject replies to peers. The client's DCC session list was empty afterward.

EPIC6 has removed the built-in `/dcc` command and associated implementation, so neither form closes connections in the current client. See [DCC Close](ctcp_close.txt) for the historical type and peer selectors. This removed command is not an operation for closing ordinary IRC server connections.
