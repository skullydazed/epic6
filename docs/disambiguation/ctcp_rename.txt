# DCC RENAME (removed)

## Former synopsis

```irc
/dcc rename [<nick>] <name> [<new-name>]
/dcc rename -chat <dcc-nick> <new-nick>
```

## Description

Historically, DCC Rename changed the local filename for an offered incoming transfer so the downloaded file could be saved under another name instead of replacing an existing file. It changed the offer's destination name, rather than renaming an existing local file on disk.

With `-chat`, it changed the local name of a DCC Chat peer. Subsequent references used that new name, including the `=` prefix in contexts expecting a nickname. This was local DCC naming, not a change to the peer's IRC nickname.

EPIC6 has removed the built-in `/dcc` command and DCC implementation. Neither the file-offer form nor `-chat` is supported by the current client. See [DCC Chat](ctcp_chat.txt) and [DCC Get](ctcp_get.txt) for related historical interfaces.

## Historical examples

These identify obsolete configurations and are not supported EPIC6 operations:

```irc
/dcc rename joebob foo bar
/dcc rename -chat joebob jimbob
```

The first changed the local destination name of Joebob's offered file from `foo` to `bar`. The second changed the local DCC Chat name to `jimbob`, subsequently addressed as `=jimbob`.
