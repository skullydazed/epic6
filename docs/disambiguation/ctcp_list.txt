# DCC LIST (removed)

## Former synopsis

```irc
/dcc list
```

## Description

Historically, DCC List displayed all active and pending DCC connections. The listed information included connection type, the original document's “entropic” indicator, peer nickname, current status, opening time, and file-transfer size, throughput, and filename where applicable.

The command invoked the former `ON DCC_LIST` hook. With `DCC_LONG_PATHNAMES` off, the filename display showed only its final path component.

EPIC6 has removed the built-in DCC command and implementation, the `DCC_LIST` event, and the `DCC_LONG_PATHNAMES` setting. This command no longer provides a connection list, and the historical hook and filename-display rules do not apply to the current client. Retained scripts cannot restore the removed primitives merely by referring to them.

See [DCC Chat](ctcp_chat.txt), [DCC Get](ctcp_get.txt), and [DCC Close](ctcp_close.txt) for related historical operations.
